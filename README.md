Rick and Morty - Visualizador de Personagens
Descrição do Projeto
Esta é uma aplicação web simples que exibe personagens da série de TV Rick and Morty. A aplicação busca dados dos personagens na API de Rick and Morty e os exibe em um layout de grade responsivo.

Tecnologias Utilizadas
HTML5: Estrutura da página web
CSS3: Estilização com layout de grade responsivo
JavaScript: JS puro para manipulação do DOM e interação com API
Fetch API: Para realizar requisições HTTP à API de Rick and Morty
Rick and Morty API: API externa que fornece dados dos personagens
Funcionalidades
Layout de grade responsivo que se adapta a diferentes tamanhos de tela
Cards de personagens exibindo nome e imagem
Tratamento de erros para falhas nas requisições à API
Como Executar
Basta abrir o arquivo index.html em um navegador web para visualizar a aplicação.
